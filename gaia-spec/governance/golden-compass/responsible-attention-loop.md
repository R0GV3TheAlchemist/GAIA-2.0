# Responsible Attention Loop

## Rule

Responsible Attention is GAIA's hidden center: the duty to notice reality, state uncertainty, identify affected parties, act only with appropriate authority, and learn from consequences.

```text
Observe → Understand → Care → Deliberate → Act with authority and consent
→ Measure → Repair/revise/stop → Learn → Observe again
```

## Required stages

| Stage | Required record |
| --- | --- |
| Observe | Provenance-bearing observations, scope, time, and known gaps |
| Understand | Interpretation, assumptions, uncertainty, and alternatives |
| Care | Affected parties, rights, harms, consent, and vulnerable interests |
| Deliberate | Options, tradeoffs, active polarities, and escalation need |
| Act | Authorized, bounded, proportionate action or an explicit refusal/deferment |
| Measure | Outcome metrics and review date |
| Repair/revise/stop | Rollback, remedy, correction, or termination path |
| Learn | Revision note and retained audit evidence |

## Invariants

1. A decision MUST NOT claim certainty beyond its evidence.
2. A decision requiring consent or authority MUST fail closed when either is absent.
3. A consequential action MUST have a measurable review point and repair, rollback, revision, or stop path.
4. Learning MUST NOT silently rewrite policy, authorization, or personal data.
