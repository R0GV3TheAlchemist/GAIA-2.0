# gaia-spec/aisd

Listed-only AISD taxonomy (#126 / #455).
Reading this directory does not grant a skill or open a router.

Crate already on main: `gaia-aisd` (`assign_maturity`, `protein_structure`, `banned_level6`, `REALMS`, `aisd_v1_tagged`).
This folder is the data shelf those symbols already enforce.

## Files

| File | What |
| --- | --- |
| taxonomy.csv | 13 realms + protein-structure example |
| ban-level6.csv | five domains that cannot take Maturity::L6 |

Claim class: `listed-only`. Effects empty.
`aisd_v1_tagged()` stays false.

## Refuse

- clinical action, legal representation, weapons/targeting, child accounts, unsupervised planetary actuators as L6
- unmeasured skill as L5+
- catalog row as a dispatcher or actuator
- published closed-model score as `gaia_measured`
