# gaia-sdk

Typed clients for the v0.1 primitives. These are **local stubs**: they do
not talk to a kernel. They exist so later phases can swap the transport.

## Layout

| Path | Package |
| --- | --- |
| `rust/` | crate `gaia-sdk` |
| `python/` | package `gaia_sdk` |
| `typescript/` | package `@gaia-os/sdk` |

## Future install one-liner (not live)

```text
# NOT PUBLISHED. Do not curl this. Tracked as a Phase 4/5 distribution job.
# cargo add gaia-sdk
# pip install gaia-sdk
# npm install @gaia-os/sdk
```

There is no public registry package and no `https://install.gaia.os` script.
