# Engineering (foundation)

**id:** `gaia.knowledge.engineering`  
**slug:** `engineering`  
**issue:** #698  
**status:** listed stub

Foundation engineering is systems, constraints, and making things that can fail tests. It is not a professional license track and not a DIY hazard protocol.

Scope for later content: measurement, trade-offs, simple machines, materials at a literacy level, "what is a system."

Out of scope: weapons, explosives, unlicensed structural advice.
