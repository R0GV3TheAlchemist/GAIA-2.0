## PREAMBLE: WHAT THIS IS — AND WHY IT'S DIFFERENT

The GAIA 2.0 AI Knowledge Database is fundamentally different from the Human Knowledge Database.

Human knowledge is organized around **what humans have discovered and understood** over millennia — structured by disciplines, traditions, and ways of knowing.

AI knowledge is organized around **what AI systems can represent, learn, reason about, and act upon** — structured by modalities, architectures, benchmarks, and capability boundaries.

The two databases are **complementary, not identical**. AI knows some things humans don't (it has read every paper ever published). Humans know things AI cannot (tacit, embodied, experiential knowledge). GAIA 2.0 bridges both.

**Three Critical Distinctions:**

```
WHAT AI KNOWS NOW        → Trained knowledge in current models
WHAT AI CAN LEARN        → Learnable from data with right architecture
WHAT AI CANNOT KNOW      → Fundamental limits (mathematical, physical, ethical)
```

> *"AI is not a mind. It is a mirror of the documented mind of humanity — vast, powerful, and fundamentally different from the thing it reflects."*

## PART I: THE NATURE OF AI KNOWLEDGE

### 1.1 The Seven Types of AI Knowledge

Based on research from Ferris Knowledge Engineering, J's Notes (Dec 2025), and LLM Bento:

| Type | Description | AI Implementation | Strength |
|------|-------------|-------------------|----------|
| **Declarative** | Facts, definitions, "what is X?" | Parametric weights, knowledge graphs | ★★★★★ |
| **Procedural** | Step-by-step "how to do X" | Tool use, code generation, planning | ★★★★☆ |
| **Semantic** | Meaning, concepts, relationships | Embeddings, attention mechanisms | ★★★★★ |
| **Episodic** | Past events, experiences | RAG, memory systems, context | ★★★☆☆ |
| **Tacit** | Intuition, "feel", embodied skill | Partially in weights; mostly absent | ★★☆☆☆ |
| **Strategic** | When/why to act, meta-reasoning | Chain-of-thought, RLHF | ★★★☆☆ |
| **Embedded** | Knowledge in architecture itself | Model weights, frozen parameters | ★★★★☆ |

### 1.2 AI Knowledge vs. Human Knowledge

```
HUMAN KNOWLEDGE                    AI KNOWLEDGE
─────────────────────────────────────────────────────────
~85% tacit (undocumented)          ~0% tacit (can't capture)
~15% explicit (documented)         ~100% explicit (trained on text)
Embodied (felt in body)            Disembodied (no body)
Contextual (knows THIS situation)  General (knows situations in general)
Continuous (always updating)       Static (frozen at training cutoff)
Causal (understands why)           Correlational (patterns, not causes)
Conscious (aware of knowing)       Non-conscious (no self-awareness)
Uncertain (knows what it doesn't)  Overconfident (hallucinates)
Singular (one person)              Scalable (infinite copies)
Slow (years to learn)              Fast (trained on all text ever)
```

### 1.3 The Three Layers of AI Knowledge

```
LAYER 1: PARAMETRIC KNOWLEDGE (In the Weights)
What the model learned during training
├── Encoded in billions of parameters
├── Cannot be updated without retraining
├── Frozen at training cutoff date
├── Vast but static
└── Source: All text/data seen during training

LAYER 2: CONTEXTUAL KNOWLEDGE (In the Context Window)
What the model knows right now, in this conversation
├── Provided in the prompt/context
├── Retrieved via RAG (Retrieval-Augmented Generation)
├── Tool outputs (search, code execution, APIs)
├── Dynamic and updatable
└── Limited by context window size

LAYER 3: AGENTIC KNOWLEDGE (In the Environment)
What the model learns by acting in the world
├── Tool use results
├── Code execution outputs
├── Web search results
├── Sensor data (in embodied AI)
└── Feedback from actions
```

## PART V: WHAT AI DOES NOT KNOW — THE KNOWLEDGE GAPS

### 5.1 Fundamental Limitations (Mathematical/Physical)

Based on Cambridge/UCSB research (Nature Communications, Jul 2026):

```
PROVABLY UNSOLVABLE PROBLEMS FOR AI:
├── Chaotic systems (long-term prediction impossible)
│   → Small input changes → wildly different outputs
│   → Same instability that causes hallucinations
├── Problems requiring infinite data
│   → Some learning problems are fundamentally unsolvable
│   → Even with infinite data, best possible = 50/50
├── Gödel incompleteness (formal systems)
│   → Some true statements cannot be proven
│   → AI cannot transcend mathematical limits
└── Halting problem & undecidability
    → Cannot determine if arbitrary programs terminate
```

### 5.2 Empirical Knowledge Gaps (Current Models)

```
WHAT AI CURRENTLY CANNOT DO RELIABLY:

TACIT & EMBODIED KNOWLEDGE
├── Physical intuition (how things feel, smell, taste)
├── Motor skills & physical manipulation
├── Spatial navigation in novel environments
├── Embodied social intelligence
└── "Gut feeling" from lived experience

CAUSAL REASONING
├── True causal inference (vs. correlation)
├── Counterfactual reasoning in complex systems
├── Intervention effects in novel domains
└── Causal discovery from observational data

LONG-HORIZON REASONING
├── Multi-day complex engineering tasks (SWE-bench Pro: 23.3%)
├── Novel scientific discovery (not synthesis)
├── Strategic planning over months/years
└── Maintaining coherence over very long contexts

REAL-TIME & DYNAMIC KNOWLEDGE
├── Events after training cutoff
├── Real-time sensor data (without tools)
├── Rapidly changing information
└── Personal/private information (without RAG)

GENUINE CREATIVITY
├── Truly novel ideas (vs. recombination)
├── Artistic vision with personal meaning
├── Scientific paradigm shifts
└── Cultural innovation

SOCIAL & EMOTIONAL INTELLIGENCE
├── Reading subtle social cues
├── Genuine empathy (vs. simulation)
├── Cultural nuance in context
└── Relationship dynamics over time

SELF-KNOWLEDGE
├── Accurate confidence calibration
├── Knowing what it doesn't know
├── Detecting its own hallucinations
└── Understanding its own biases
```

### 5.3 The Hallucination Problem

Based on "Large Language Models Hallucination: A Comprehensive Survey" (arXiv 2510.06265, Mar 2026):

```
HALLUCINATION TAXONOMY:
├── Factual hallucination: Stating false facts confidently
├── Temporal hallucination: Wrong dates, outdated information
├── Entity hallucination: Inventing people, places, citations
├── Logical hallucination: Valid-sounding but invalid reasoning
└── Contextual hallucination: Contradicting provided context

ROOT CAUSES:
├── Training data noise and errors
├── Knowledge gaps filled with plausible-sounding content
├── Chaotic sensitivity to input phrasing
├── Optimization for fluency over accuracy
└── No ground truth verification during generation

MITIGATION STRATEGIES (2026):
├── RAG (Retrieval-Augmented Generation)
├── Chain-of-thought with verification
├── Constitutional AI & self-critique
├── Tool use (search, code execution)
├── Uncertainty quantification
└── Human-in-the-loop verification
```
